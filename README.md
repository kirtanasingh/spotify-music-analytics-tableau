# Spotify Music Analytics Dashboard 🎵

An interactive **Spotify Music Analytics Dashboard** built using **Tableau Public** to analyze music popularity, danceability, genres, and artist performance.

## 📊 Dashboard Overview

The dashboard provides a visual analysis of Spotify tracks and includes multiple views to understand patterns in music popularity and genre distribution.

### Key Visualizations

* **Popularity vs Danceability**

  * Analyzes the relationship between average track popularity and danceability.

* **Top 10 Genres by Average Popularity**

  * Identifies the 10 genres with the highest average popularity.

* **Top 10 Artists by Average Popularity**

  * Compares artists based on their average track popularity.

* **Genre Distribution**

  * Visualizes the distribution of tracks across different music genres.

* **Popularity Distribution by Genre**

  * Shows the spread and variation of popularity across genres.

## 🛠️ Tools & Technologies

* **Tableau Public** — Data visualization and dashboard development
* **Spotify Dataset** — Music track, artist, genre, and popularity data
* **Data Analysis** — Aggregation, filtering, comparison, and distribution analysis

## 📈 Key Insights

The dashboard can be used to explore questions such as:

* Which genres have the highest average popularity?
* Which artists have the highest average popularity?
* Is there a relationship between danceability and popularity?
* How are tracks distributed across different genres?
* How does popularity vary within individual genres?

## 🚀 How to Use

1. Download the `.twbx` Tableau packaged workbook from this repository.
2. Open it using **Tableau Public Desktop** or a compatible Tableau application.
3. Explore the individual worksheets and the interactive dashboard.
4. Use the available visualizations and filters to analyze the Spotify data.

## 🎯 Project Objective

The objective of this project is to transform Spotify music data into an interactive visual analytics dashboard that makes it easier to identify patterns in **music popularity, artist performance, danceability, and genre distribution**.
